# 🛒 E-Commerce Sales & Returns Analysis

## 📌 Project Overview

This project analyzes e-commerce sales and returns data using **Microsoft Excel** to identify important business trends, revenue patterns, customer segments, acquisition channels, and refund behavior.

The project demonstrates practical **Data Analyst skills**, including data cleaning, data transformation, PivotTable analysis, PivotCharts, interactive slicers, and dashboard development.

---

## 🎯 Business Objective

The main objective of this project is to answer key business questions such as:

- How does net revenue change over time?
- Which countries generate the highest revenue?
- Which acquisition channels perform best?
- Which customer segments contribute the most revenue?
- What is the distribution of order statuses?
- How much revenue is lost through refunds?
- How do refunds change over time?

---

## 🗂️ Dataset

The dataset contains e-commerce order-level information, including:

- Order ID
- Order Date
- Order Status
- Customer ID
- Country
- Acquisition Channel
- Customer Segment
- Line Count
- Units
- Subtotal
- Tax Amount
- Shipping Amount
- Gross Payment
- Refund Amount
- Net Revenue

The dataset contains approximately **100,000 orders**.

---

## 🧹 Data Cleaning & Preparation

The dataset was prepared in Microsoft Excel before analysis.

### Cleaning steps performed:

- Checked the structure and columns of the dataset
- Converted date-related information into usable Year and Month fields
- Created a Month Name field
- Created a Quarter field
- Created Refund Flag
- Created Cancellation Flag
- Converted revenue-related fields into numeric values
- Verified PivotTable calculations
- Prepared the dataset for analysis

---

## 📊 Analysis Performed

Six main analytical views were created using Excel PivotTables.

### 1. Monthly Net Revenue

Analyzes net revenue by:

- Year
- Month

This helps identify revenue trends and seasonal patterns.

### 2. Revenue by Country

Compares net revenue across different countries to identify the strongest markets.

### 3. Revenue by Acquisition Channel

Analyzes performance across:

- Organic
- Paid Search
- Paid Social
- Referral
- Affiliate

### 4. Revenue by Customer Segment

Compares revenue generated by:

- Consumer
- Small Business
- Enterprise

### 5. Orders by Status

Analyzes the distribution of:

- Completed
- Cancelled
- Refunded
- Partially Refunded

### 6. Refund Analysis

Analyzes refund amounts over time to identify refund trends.
